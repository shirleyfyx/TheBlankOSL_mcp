## Abstract

The Blank OSL is a state-of-the-art operating system abstraction layer that utilizes NLP and LLMs to improve OS navigation and operations for all users globally. Aiming to help people leverage more operating system utilities without the need to spend time studying obscure commands, the Team Vertex’s newest innovation allows computer users to directly control the operating system’s behavior through natural language input such as text or voices. With the widespread use of GUI based operating systems like Windows or macOS, it is less incentivized for users to learn terminal navigation, which prevents them from taking full advantage of the operating system. Therefore, our objective is to create an operating system abstraction layer that acts as an intermediary between a normal terminal and GUI, allowing everyone to easily exploit the power of computers without requiring a deep knowledge of the computer architecture or terminal commands.

The Blank OSL provides a navigable terminal that runs purely off natural language text inputs, as if the users have typed in the terminal commands. The operating system layer also provides a predefined protocol that allows applications to communicate with each other. The Blank OSL runs on top of existing operating systems to manage the hardware resources and processes. It provides a terminal to process the user’s natural language input and sends these inputs to a fine-tuned LLM and parses the natural language into tokens based on a predefined grammar. The Blank OSL then uses the built-in interpreters to execute these tokens to communicate/execute actions based on a custom communication protocol. The resulting product would provide more control to the user, as opposed to a GUI, but be more accessible as compared to a normal OS terminal. The product would prove integral for users due to its flexibility in performing an endless amount of tasks. Improved usability is also expected due to the influx in efficiency handling tasks on the computer.

Overall, The Blank OSL will be a revolutionary product that helps to aid people around the world gain more control for their computers, whilst maintaining a low barrier of entry to a computer level below the generic GUI.
