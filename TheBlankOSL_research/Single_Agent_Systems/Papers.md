## Natural Language to Code Translation with Execution

- **Authors**: Freda Shi, Daniel Fried, Marjan Ghazvininejad, Luke Zettlemoyer, Sida I. Wang
- **Summary**: This paper introduces the execution result-based minimum Bayes risk decoding (MBR-EXEC) to improve the performance of models translating natural language descriptions to executable code. The core problem it addresses is selecting the most functionally correct program from a set of generated candidates. By using execution results during the selection process, the accuracy of code generation models is significantly improved.
- **Key Contributions**:
  - Proposed MBR-EXEC, a novel method that selects programs based on execution results, optimizing for functional correctness rather than just syntactic similarity.
  - Demonstrated the effectiveness of MBR-EXEC across several programming languages and datasets (Python, SQL, Bash).
  - Showed that execution result-based selection outperforms traditional methods, even without access to ground-truth outputs.
  - Highlighted the method's ability to work effectively in few-shot learning scenarios, improving code generation models like Codex.
