01 ABSTRACT

The Blank Operating System Layer makes OS control more expressive via an LLM, a client, and multiple servers communicating through the Model Context Protocol (MCP).

Servers span three primary categories: Filesystem (read, write, search), Process Manager (spawn, monitor system attributes), and Miscellaneous (extensible plugins like weather or Wikipedia).

The client parses natural-language tasks, formats them via an LLM (such as Gemini, ChatGPT, or local alternatives), and exposes underlying operation details for user review prior to local execution.

05 CORE CAPABILITIES

The Blank OSL seamlessly orchestrates multiple async servers through a robust plugin architecture:

  • Filesystem: 15+ asynchronous operations (read, write, search, copy, move) powered by aiofiles, complete with deep regex metadata search.
  • Archive Manager: Secure, Tar-Slip protected async compression and decompression for ZIP, 7z, and TAR formats.
  • Contacts Manager: Comprehensive CRUD functionality and full-text search capabilities backed by aiosqlite.
  • LLM Sampling: Formats dynamic tool manifests into system prompts and accurately parses TOOL_CALL JSON blocks using LLM.
  • Config & Settings: Global CLI state management at ~/.blankosl_cli/ ensuring atomic temp-file writes and environment variable expansion.
