01 ABSTRACT

The Blank Operating System Layer makes OS control more expressive via an LLM, a client, and multiple servers communicating through the Model Context Protocol (MCP).

Servers span three primary categories: Filesystem (read, write, search), Process Manager (spawn, monitor system attributes), and Miscellaneous (extensible plugins like weather or Wikipedia).

The client parses natural-language tasks, formats them via an LLM (such as Gemini, Groq, or local alternatives), and exposes underlying operation details for user review prior to local execution.

02 SYSTEM ARCHITECTURE
04 HOW IT WORKS
1
Configure
Load MCP server definitions and persist local CLI settings for reliable reuse.
config/load
2
Connect
MCPManager starts each server as a subprocess, opens JSON-RPC communication channels, and completes MCP initialization before any tools are exposed.
session/start
3
Discover
The client queries every connected server for available tools, then merges their schemas into a unified capability list for the LLM and user.
tools/list
4
Chat & Review
The LLM translates natural-language requests into a structured tool call by matching against available MCP tools, then presents the proposed action to the user for confirmation before execution.
5
Execute
Approved calls are dispatched over JSON-RPC, results are collected from the target server, and outputs are fed back into the session for multi-step follow-up tasks.
tools/call
05 CORE CAPABILITIES

The Blank OSL seamlessly orchestrates multiple async servers through a robust plugin architecture:

  • Config & Settings: Global CLI state management ensuring flexible on-the-fly API key and environment variable management.
  • Confirmation Dialog: Prompts users to confirm MCP actions before execution, adding a safety layer for sensitive operations.
  • MCP Server Integration: Enables users to dynamically connect custom MCP servers through the CLI, supporting both local servers and commands that interface with remotely hosted services.
  • Filesystem: Asynchronous operations (read, write, search, copy, move) powered by aiofiles, complete with deep regex metadata search. Supports common file formats such as CSV, PDF, TXT, JSON, and more.
  • Contacts Manager: Comprehensive contact management with full CRUD operations backed by aiosqlite, integrated with email capabilities to read, and send messages using saved contact information.
